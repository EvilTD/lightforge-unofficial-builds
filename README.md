# Unofficial Lightforge Builds

This repository provides unofficial, automated builds of [Lightforge](https://github.com/LibreStatic/lightforge), created by **FacuM**, the original developer of the project.

## About this repository

This is an independent repository maintained to automate the building and distribution of unofficial Lightforge APKs.

These builds are not official releases, are not endorsed by, and are not affiliated with the original developer.

APK files published here are signed with an independent signing key and are not signed by the original developer.

**This repository does not claim ownership of Lightforge or its name, branding, or original code.**

For the official project and its development, always visit the original repository above.
